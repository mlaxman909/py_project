# 🏫 School Management System

A Python OOP project for managing students and teachers with JSON data persistence.

## Features
- Register students and teachers
- Add grades/marks per subject
- View student details with average marks
- Data persists using JSON file storage
- Email validation built-in
- Duplicate entry prevention

## OOP Concepts Used
- Abstract Classes (ABC)
- Inheritance (Student, Teacher extend Person)
- Static Methods (email validation)
- Encapsulation

## How to Run
```bash
python main.py
